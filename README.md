# Trader Behavior Analysis Using Market Sentiment

## Objective
To analyze the relationship between Bitcoin market sentiment and trader performance using historical trading data.

## Dataset
- Bitcoin Fear & Greed Index
- Historical Trader Data (Hyperliquid)

## Approach
- Data cleaning and preprocessing
- Exploratory data analysis
- Sentiment-based performance analysis
- Machine Learning model (Random Forest)
- Insight generation

## Key Findings
- Market sentiment strongly impacts trading performance
- Fear-based markets offer better risk-adjusted returns
- Sentiment alone is not sufficient for accurate profit prediction
- Trading behavior and volume play a major role

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Conclusion
This project demonstrates how sentiment-driven analysis can help understand trader behavior and improve trading strategies in crypto markets.
